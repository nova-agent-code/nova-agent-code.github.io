What Nova Agent is

Nova Agent is an autonomous AI coding agent for Windows, created and developed by Manish Al Rabbani. It is designed to help developers read and modify code, work with files, run terminal commands, manage development processes, and complete coding tasks with AI.

Instead of only suggesting snippets, Nova Agent plans a task, reads the project, runs commands through a gated execution layer, and returns a reviewable result: a diff, a test run, and a log of every tool call it made. It is free to use with your own API key across 110+ LLM providers, and it collects no telemetry.

The official website

Nova Agent Code — nova-agent-code.github.io — is the official website of the project. It presents what Nova Agent does, publishes the Windows installer and release notes, and hosts the built-in updater, privacy policy, and terms of service. Releases are distributed through the project's GitHub repository.
