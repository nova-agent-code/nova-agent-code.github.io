Features

Built to run the whole task,
not just the next line.

Every subsystem exists to let the agent work longer, safer, and with far less context bloat — without you watching it.

Hard Tool Execution Gate

Nothing runs without passing a hard gate. Every shell command, file write, and process spawn is validated against policy before a single byte executes.

Deterministic safety

Atomic Tool-Pair Eviction

Tool calls are evicted as intact pairs — never a dangling call without its result. Context stays coherent no matter how long the session runs.

Zero broken state

Eviction Distillation

Evicted history is distilled, not dropped. Key decisions, file paths, and constraints survive compression so the agent never forgets why it did something.

Long-horizon memory

PID Background Processes

Dev servers, watchers, and builds run as tracked PID processes in the background — started, monitored, and cleanly terminated by the agent.

Real multitasking

110+ LLM Providers

OpenAI, Anthropic, Gemini, DeepSeek, Mistral, local Ollama models and more — swap providers per task without changing a single line of your workflow.

Vendor neutral

100% Free & BYOK

No subscription, no seat pricing, no usage metering. Bring your own API key — your code and your prompts never touch our servers.

Zero lock-in

Security

Autonomy with a hard kill-switch.

An agent that can run a terminal needs more than good intentions. Nova Agent enforces safety at the execution layer, not the prompt layer.

  • ✓

    Execution allow-list

    Only whitelisted command patterns reach the shell. Everything else is rejected outright.

  • ✓

    Scoped filesystem access

    Reads and writes are confined to your project root. No wandering outside the workspace.

  • ✓

    Local-first by design

    Prompts, source files, and keys stay on your machine. We collect no telemetry.

  • ✓

    Instant interrupt

    Stop any running tool, process, or plan with a single key at any moment.
